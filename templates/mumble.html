Mumble bots

The stv.tf voice bot brings a team's channel into a live match: delayed so it matches SourceTV, and stored in the demo.

Each match

  1. Start the match on stv.tf.
  2. On the page: 🔊, Comms, Mumble.
  3. Server, password, channel: Connect.

The bot joins at once, and shows that it records. The other team's channel is added in the same menu.

Only while the match is live: comms cannot be added to a demo afterwards.

Certificates

The bot signs in by one of these certificates, the same every time; a second bot on a server at the same time, uses the second, and so on.

Check: right-click the bot, Information: its certificate's SHA-1 is in this list.

Register: have the bot join once (a match's Comms menu, Mumble), then right-click it, Register. It is the same bot from then on.

More than one team: register stv.tf-2 the same way, while two bots are in.
