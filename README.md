# stvtf-web

The server behind [stv.tf](https://stv.tf): a live top-down view of a TF2 match in the browser.
It links [stvtf](../stvtf) as a library: one SourceTV connection per match, fanned out to any
number of browsers over Server-Sent Events.

```
cargo build --release
./target/release/stvtf-web                     # paste connect strings at http://127.0.0.1:8080/
./target/release/stvtf-web HOST:TVPORT         # watch one server
./target/release/stvtf-web --replay FILE.jsonl # play a saved stvtf output
```

`--help` lists every option.
